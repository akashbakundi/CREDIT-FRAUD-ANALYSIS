# Credit Card Fraud Analysis

## Overview
This project analyzes credit card transactions to detect fraudulent activity using **Excel** for data preparation and **Power BI** for visualization. The goal is to simulate how a financial institution’s fraud analytics team monitors suspicious transactions and presents executive dashboards for decision-making.

## Key Fraud Indicators
- **Velocity Score:** Average fraud velocity observed at 19.81, highlighting transaction speed anomalies.
- **Fraud Totals:** 0.11M flagged transactions (4.01%) vs. 2.6M legitimate transactions (98.06%).
- **Shipping Mismatch:** 0.05M cases (1.94%) where shipping details did not match billing.
- **AI-Generated Scam Attempts:** Identified and flagged as part of anomaly detection.

## Authentication & Card Type Analysis
- **Authentication Methods:** 3D Secure, OTP, PIN, Biometric, and No Authentication.
- **Card Types:** Visa, Mastercard, Amex dominate usage; RuPay and Discover observed in smaller volumes.

## Merchant & Channel Insights
- **Merchant Risk Score:** Average risk score of 37.40 across merchants.
- **Transactions via VPN:** 1.76K (8.8%) flagged as potentially risky.
- **Merchant Categories:** Online Retail (17%), Groceries, Restaurants, Electronics, Fuel, Travel, Utilities, Healthcare, Gaming, Streaming, Gift Cards, Crypto Exchange.
- **Transaction Channels:** Online, POS, Contactless, In-App, ATM.

## Results
- Fraud detection highlighted **high-risk merchant categories** and **authentication gaps**.
- VPN-based transactions and shipping mismatches emerged as strong fraud signals.
- Dashboards provide executives with fraud KPIs, transaction counts, and merchant risk profiles.
